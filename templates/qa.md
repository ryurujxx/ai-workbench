## 원문 위치 색인·제한 시 폴백
- L-ID → 실제 비공개 원문 경로·메시지/구간·출처/수신 순서·내용 지문 / 구 위치·앵커 대응:
- 별도 로그 파일 생성 금지일 때만: 기존 허용 qa의 접기/보관 블록에 L-ID·원문 전체를 한 번 보존하고 여기서 연결한다. 금지 위치에 새 파일을 만들지 않는다.

B 원문 보관/정확한 전사·발췌/참조만 기획에게 허용한다. 원문 소유권은 사용자에게 있고 기존 원문 수정·의미 변경·가상 답변은 금지한다. 중복 로그는 재기록하지 않으며 이름/시각·역할/Q가 모호하면 추측하지 않는다. 질문 관리는 모든 기획 활동의 기본 의무이며 [공통 의무](../WORKFLOW.md#기획-중-질문-발견기록전달-묶음)를 적용한다. 새 질문/근거/상태 변화가 없으면 저장하지 않는다. 실제 대화/개인정보는 공개 워크벤치·원격에 반입하지 않는다.
