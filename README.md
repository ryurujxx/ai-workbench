# AI 개발 워크벤치

요구사항 탐색부터 구현·검증·기술 학습까지 연결하는 범용 워크벤치다. 핵심 원칙은 **승인된 기능은 즉시 구현하고, 구현된 기능은 즉시 검증하며, 중요한 선택·오류·결과는 즉시 STUDY에 남기는 것**이다.

처음에는 [AGENTS.md](AGENTS.md), [START.md](START.md), [WORKFLOW.md](WORKFLOW.md)만 읽는다.

| 파일 | 역할 |
|---|---|
| [AGENTS.md](AGENTS.md) | 역할·권한·보안 원칙 |
| [START.md](START.md) | 기획 우선 진입과 역할별 실전 프롬프트 |
| [WORKFLOW.md](WORKFLOW.md) | 질문·승인·H/T 인계·개발·검증·제출 계약 |
| [templates/STUDY.md](templates/STUDY.md) | 실제 프로젝트에 만들 학습 기록 양식 |
| [references/SOURCES.md](references/SOURCES.md) | 외부 공개 자료의 출처·라이선스 확인 범위 |

## 빠른 시작

1. 실제 프로젝트 폴더에서 기획 담당 Codex 세션을 먼저 연다.
2. 환경 정책이 허용하면 이 저장소를 허용된 참고 경로에 Clone한다. 한 작업공간만 사용할 수 있으면 프로젝트 내부의 별도 하위 폴더를 사용할 수 있지만 기존 파일·Git 구조와 충돌하지 않는지 먼저 확인한다.
3. 아래 요청을 입력하고 [START.md](START.md)의 기획 절차를 따른다.

```text
너는 기획 담당이야. 현재 프로젝트와 과제 자료를 수정 없이 탐색해. README.md를 초기 지시서 후보로 먼저 확인하되 실제 지시·제공 자료를 기준으로 판단해. 환경의 Clone·외부 자료·Push·업로드·외부 API 정책과 제한시간을 확인하고, 최소 도메인 분석과 1차 업무자 질문을 준비해. 독립 구현 후보는 사용자 승인 전까지 확정으로 표시하지 말고, 승인된 항목만 버전 있는 H 패킷으로 작성해. START.md를 읽을 수 없으면 필요한 핵심 절차를 내가 붙여 넣을 수 있다고 알려줘.
```

승인된 첫 H 패킷이 나오면 구현 담당을 시작해 프로젝트 내부에 최소 `STATUS.md`와 `STUDY.md`를 만든다. 구현 완료 기능이 생기면 테스트 담당을 시작한다. 세 세션의 대화는 자동 공유되지 않으므로 STATUS와 H/T 패킷으로 연결한다.

환경별 보안 정책이 최우선이다. 외부 반출 제한 환경에서는 원격 Push·업로드·외부 API 전송을 하지 않는다. 일반 개발 환경에서는 허용된 작업 브랜치 협업을 사용할 수 있다. 실제 비공개 문제·데이터·로그·결과물은 이 공개 저장소에 포함하지 않는다.
