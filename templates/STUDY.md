# STUDY

실제 프로젝트 내부에 두는 학습 기록 양식이다. 사용자가 구현과 문제 해결을 자신의 말로 설명하도록 돕는다. 구현 담당이 단일 작성자로 관리하고, 중요한 결정·오류·검증이 생길 때만 짧게 갱신한다.

실행하지 않은 실험, 발생하지 않은 오류, 비교하지 않은 대안을 만들지 않는다. 모든 주장은 요구사항 ID·코드·커밋·로그·테스트 결과 중 실제 근거를 가리킨다.

## 현재 학습 우선순위

실제 구현에서 확인된 주요 기술 선택·알고리즘·중요 오류·검증 결과 중 사용자가 먼저 이해해야 할 내용만 최대 3개로 유지한다. 이미 학습한 내용과 아직 확인되지 않은 사항을 구분하고, 실제 근거가 없는 항목은 추가하지 않는다.

| 우선순위 | 먼저 이해할 내용 | 구분 | 실제 근거 |
|---|---|---|---|
| 1 | [기술 선택·알고리즘·오류·검증 결과] | 학습 필요/학습함/미확인 | [요구사항·코드·SHA·로그·T-ID] |

학습이 끝났거나 우선순위가 바뀌면 실제 진행 상태에 맞게 교체한다. `학습함`은 사용자가 설명하거나 이해 확인을 마친 경우에만 쓰고, 근거는 있으나 결과가 확정되지 않은 내용은 `미확인`으로 표시한다.
