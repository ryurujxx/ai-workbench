# 근거 누적·결과 보고 양식

읽기 전용 양식이다. 프로젝트 지정 경로를 우선하고, 없으면 작업공간 안에 기록 위치를 한 번 정한다. 동명 파일을 먼저 확인하고 STATUS에 문서별 실제 경로를 명시한다. 마지막에 기억으로 새로 작성하지 않고 결정·오류·검증이 생길 때 아래 근거 색인을 짧게 누적한 뒤 인계 시 실제 코드·로그·테스트와 대조한다. 아래 가상 예시를 실제 작업 이력으로 사용하지 않는다.

## 빈 양식

- 문제 정의·목표·합의 범위와 근거:
- 공개 평가 항목·배점·서술형 질문:
- 실행법·환경·입력:
- 최종 설계·구현 ID·핵심 파일과 근거:
- 기술·알고리즘·라이브러리 선택 이유와 DECISIONS 근거:
- 비교·배제 대안과 선택 근거:
- 오류·해결 과정과 VERIFICATION 근거: 증상 / 재현 / 원인 또는 가설 / 변경 / 재검증
- 테스트 방법·실제 결과: 요구사항 / 기대값 / 실제값 / 수행자·출처 / 판정 / 증거
- 미구현:
- 실패:
- 미검증:
- 해당 없음과 이유:
- 한계·추가 개선 방향:
- 사용자 설명 제공/이해 확인 상태:
- 최종 제출 결과·확인 근거:

각 항목은 가능한 한 정본 ID, 코드 경로, 로그 또는 실행 시점을 가리킨다. 아직 최종 결정이 아니면 현재 상태와 미확인을 유지한다. 상세 내용을 중복 복사하기보다 DECISIONS·VERIFICATION의 근거를 연결한다.

### 평가 추적

| 평가 ID·항목 | 공개 배점/미제공 | 요구사항 ID·버전 | 구현 기능·파일·커밋 | 검증 T-ID·판정 | 증거 위치 | 상태 |
|---|---|---|---|---|---|---|
| [E-ID] | [점수/미제공] | [R-ID v#] | [기능·경로·SHA] | [T-ID·통과/실패/미검증] | [로그/정본] | 충족/부분/미충족/미확인 |

### 서술형 근거

| 질문 ID·원문 | 연결 결정·오류·테스트 | 실제 근거 | 미확인·한계 |
|---|---|---|---|
| [Q-ID] | [D-ID/E-ID/T-ID] | [코드·로그·결과] | [실행하지 않은 항목] |

## 가상 작성 예

- 정의된 범위: 요청 등록·공백 차단·상태 전이·완료 역전이 차단(EX-R1~EX-R4)
- 구현: 없음. 네 항목 모두 미구현
- 실행법: 구현하지 않아 미정
- 검증: 네 항목 모두 미검증, 실제 결과 없음
- 선택: 삭제·로그인 제외라는 가상 합의
- 수정 이력: 없음
- 한계: 문서 흐름만 보여주는 예시
- 사용자 이해: 설명 질문만 제시, 확인하지 않음
